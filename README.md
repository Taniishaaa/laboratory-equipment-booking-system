# Laboratory Equipment Booking System

## Project Overview

The Laboratory Equipment Booking System is an MVP designed to simplify the process of booking laboratory equipment and managing available time slots.

## MVP Features

- User registration
- Equipment availability and slot viewing
- Booking requests
- Booking confirmation
- Booking cancellation
- Booking status tracking

## Technology Stack

- Frontend: React + Vite
- Backend: Node.js + Express
- Database: PostgreSQL
- ORM: Prisma
- Build Tool: Maven
- Testing: Selenium
- CI/CD: Jenkins
- Containerization: Docker
- Configuration Management: Ansible

## Project Structure

- `frontend/` – Frontend application
- `backend/` – Backend application
- `tests/` – Automated test cases
- `docs/` – Project documentation
- `.github/` – GitHub templates and repository configuration

## Development Workflow

The project follows an Agile DevOps workflow:

Git → GitHub → Jenkins → Build → Selenium Testing → Docker → Deployment → Configuration Management

The project is currently under development.
